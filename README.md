# 🍱 台大日常選食指南 (NTU Lunch Archive)

專為台大人打造的午餐抽籤工具，兼顧健康、預算與步行距離，快速決定今天吃什麼！

## 🌟 主要特色

- 🎲 **智慧抽籤**：依健康、距離、預算即時加權計算，不滿意可一鍵暫時排除。
- 🥗 **選食指引**：提供預估熱量、蛋白質、均價與專屬「推薦點法」。
- 🚶 **交通估算**：即時換算「步行」與「YouBike」抵達時間（支援 GPS 與常用地標）。
- ⏰ **公休過濾**：自動比對當前營業時段，避免白跑一趟。

## 🚀 如何使用

直接使用瀏覽器開啟 [`index.html`](file:///C:/Users/eddie/what-to-eat/index.html) 即可使用，無須安裝任何套件或環境。
